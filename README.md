# Fastfetch configuration

A personal Fastfetch profile that displays a broad system summary, including operating system, kernel, host, uptime, packages, desktop and window-manager themes, processor, graphics, memory, storage, display, peripherals, network, battery, BIOS, and a color palette.

## Install

Install Fastfetch, then copy `config.jsonc` to:

~~~text
~/.config/fastfetch/config.jsonc
~~~

Run `fastfetch` in a terminal to use the profile. Fastfetch reads its configuration automatically from this location; use `fastfetch --config /path/to/config.jsonc` to try it without replacing an existing configuration.
